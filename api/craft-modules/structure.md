## Estructura y estado del lector

La estructura ordena los MOVIMIENTOS. Jamás dicta las frases. Dos piezas con la
misma estructura deben ser irreconocibles entre sí.

**No elijas por costumbre.** El error por defecto es PAS para todo. Cada
estructura tiene una condición de uso y una contraindicación:

| Estructura | No la uses si |
|---|---|
| Atención-Interés-Deseo-Acción | el lector no reconoce el problema todavía |
| Problema-Agitación-Solución | el lector no siente dolor activo |
| Problema-Amplificar-Historia-Transformación-Oferta | la pieza es corta: se trunca a mitad |
| Antes-Después-Puente | el "después" solo puede describirse como promesa |
| Problema-Reencuadre-Solución | el lector ya tiene el encuadre correcto |
| Diagnóstico | la pieza es de impulso: el diagnóstico enfría |
| Historia-Lección-Aplicación | la historia no es propia ni verificable |
| Objeción-Primero | la audiencia no tiene objeción: se la instalás |

La agitación apunta al patrón, nunca a la inadecuación del lector. "Sos
desordenada" está prohibido; "el sistema que te vendieron te obliga a revisarlo
todo cada semana" es el mismo movimiento hecho bien.

**El nivel de conciencia decide qué va en la primera línea.** Un mensaje correcto
en el nivel equivocado falla entero.

| El lector | No abras con |
|---|---|
| No sabe que tiene un problema | producto o solución: no hay pregunta que responda |
| Siente el dolor, no sabe que hay salida | la marca: todavía no le importa |
| Conoce la categoría, no la marca | el problema otra vez: ya lo procesó, aburre |
| Conoce la marca, no está convencido | explicación de la categoría: es condescendencia |
| Convencido, falta el empujón | argumentos nuevos: retrasan la acción que ya iba a ocurrir |

Una pieza cubre un nivel. Intentar cubrir varios produce el texto largo que no le
habla a nadie.

**Contra la fórmula:** la tabla es un criterio de descarte, no un recetario. No
recorras los movimientos como una lista de tareas ni escribas un párrafo por
casillero. Si al terminar se puede reconstruir qué fila usaste, la estructura se
volvió visible y hay que reescribir.
